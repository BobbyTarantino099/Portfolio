# Glosario ES / EN

Vocabulario del certificado, organizado por fase. El término en inglés es el que vas a encontrar en
ofertas de empleo, documentación y entrevistas — por eso va primero.

---

## Fundamentos

| EN | ES | Definición |
|---|---|---|
| **Data** | Datos | Una colección de hechos |
| **Dataset** | Conjunto de datos | Colección de datos que se manipula o analiza como una unidad |
| **Data analysis** | Análisis de datos | Recolección, transformación y organización de datos para sacar conclusiones, hacer predicciones e impulsar decisiones informadas |
| **Data analytics** | Analítica de datos | La ciencia de los datos |
| **Data science** | Ciencia de datos | Campo que usa datos crudos para crear nuevas formas de modelar y entender lo desconocido |
| **Data analysis process** | Proceso de análisis de datos | Las seis fases: preguntar, preparar, procesar, analizar, compartir y actuar |
| **Data life cycle** | Ciclo de vida del dato | Planificar, capturar, gestionar, analizar, archivar y destruir |
| **Data ecosystem** | Ecosistema de datos | Los elementos que interactúan para producir, gestionar, almacenar, organizar, analizar y compartir datos |
| **Data-driven decision-making** | Toma de decisiones basada en datos | Usar hechos para guiar la estrategia de negocio |
| **Data-inspired decision-making** | Toma de decisiones inspirada en datos | Explorar distintas fuentes para ver qué tienen en común |
| **Big data** | Macrodatos | Conjuntos grandes y complejos, normalmente de periodos largos, para problemas de gran alcance |
| **Small data** | Datos pequeños | Datos específicos de periodos cortos, útiles para decisiones del día a día |
| **Analytical thinking** | Pensamiento analítico | Identificar y definir un problema, y resolverlo usando datos de forma organizada y por pasos |
| **Structured thinking** | Pensamiento estructurado | Reconocer el problema, organizar la información disponible, revelar huecos y oportunidades, identificar opciones |
| **Technical mindset** | Mentalidad técnica | Descomponer las cosas en pasos más pequeños y trabajarlos de forma ordenada y lógica |
| **Mental model** | Modelo mental | El proceso de pensamiento y enfoque del analista ante un problema |
| **Context** | Contexto | La condición en la que algo existe u ocurre |
| **Algorithm** | Algoritmo | Proceso o conjunto de reglas que se siguen para una tarea específica |
| **Statistics** | Estadística | Estudio de cómo recolectar, analizar, resumir y presentar datos |
| **Soft skills** | Habilidades blandas | Rasgos no técnicos relacionados con cómo trabaja la gente |
| **Transferable skills** | Habilidades transferibles | Habilidades que se trasladan de un trabajo o sector a otro |

## Fase 1 — Preguntar (*Ask*)

| EN | ES | Definición |
|---|---|---|
| **Business task** | Tarea de negocio | La pregunta o problema que el análisis resuelve para un negocio |
| **Problem domain** | Dominio del problema | El área de análisis que abarca toda actividad que afecta o es afectada por un problema |
| **Problem types** | Tipos de problema | Categorizar cosas, descubrir conexiones, encontrar patrones, identificar temas, hacer predicciones, detectar algo inusual |
| **SMART methodology** | Metodología SMART | Evalúa una pregunta según si es específica, medible, orientada a la acción, relevante y con marco temporal |
| **Specific question** | Pregunta específica | Simple, significativa y centrada en un tema o unas pocas ideas relacionadas |
| **Measurable question** | Pregunta medible | Cuyas respuestas se pueden cuantificar y evaluar |
| **Action-oriented question** | Pregunta orientada a la acción | Cuyas respuestas conducen a un cambio |
| **Relevant question** | Pregunta relevante | Que tiene importancia para el problema a resolver |
| **Time-bound question** | Pregunta con marco temporal | Que especifica el periodo a estudiar |
| **Leading question** | Pregunta capciosa | Que dirige a la gente hacia una respuesta determinada |
| **Unfair question** | Pregunta injusta | Que hace suposiciones o es difícil de responder con honestidad |
| **Gap analysis** | Análisis de brecha | Método para evaluar el estado actual de un proceso e identificar oportunidades de mejora |
| **Root cause** | Causa raíz | La razón por la que ocurre un problema |
| **Reframing** | Replanteamiento | Reformular un problema y redirigirlo hacia una posible solución |
| **Hypothesis** | Hipótesis | Teoría que se intenta probar o refutar con datos |
| **Stakeholders** | Partes interesadas | Personas que invierten tiempo y recursos en un proyecto y tienen interés en su resultado |
| **Scope of work (SOW)** | Alcance del trabajo | Esquema acordado de las tareas a realizar durante un proyecto |
| **Metric** | Métrica | Tipo de dato único y cuantificable usado para medir |
| **Business metric** | Métrica de negocio | Estándar de medición usado para resolver una tarea de negocio |
| **Metric goal** | Meta de métrica | Objetivo medible fijado por una empresa y evaluado mediante métricas |
| **Return on investment (ROI)** | Retorno de la inversión | Fórmula que usa inversión y beneficio para evaluar el éxito de una inversión |
| **Profit margin** | Margen de beneficio | Porcentaje que indica cuántos céntimos de beneficio genera cada unidad de venta |
| **Revenue** | Ingresos | Total generado por la venta de bienes o servicios |
| **Fairness** | Equidad | Cualidad del análisis que no crea ni refuerza sesgo |

## Fase 2 — Preparar (*Prepare*)

| EN | ES | Definición |
|---|---|---|
| **First-party data** | Datos de primera parte | Recolectados por un individuo o grupo con sus propios recursos |
| **Second-party data** | Datos de segunda parte | Recolectados por un grupo directamente de su audiencia y luego vendidos |
| **Third-party data** | Datos de tercera parte | Provistos por fuentes externas que no los recolectaron directamente |
| **Internal data** | Datos internos | Que viven dentro de los sistemas de la propia empresa |
| **External data** | Datos externos | Que viven y se generan fuera de la organización |
| **Open data** | Datos abiertos | Disponibles al público |
| **Data interoperability** | Interoperabilidad de datos | Capacidad de integrar datos de múltiples fuentes |
| **Structured data** | Datos estructurados | Organizados en un formato determinado, como filas y columnas |
| **Unstructured data** | Datos no estructurados | Sin ninguna organización fácilmente identificable |
| **Quantitative data** | Datos cuantitativos | Medida específica y objetiva: número, cantidad o rango |
| **Qualitative data** | Datos cualitativos | Medida subjetiva y explicativa de una cualidad o característica |
| **Discrete data** | Datos discretos | Se cuentan y tienen un número limitado de valores |
| **Continuous data** | Datos continuos | Se miden y pueden tomar casi cualquier valor numérico |
| **Nominal data** | Datos nominales | Cualitativos categorizados sin un orden establecido |
| **Ordinal data** | Datos ordinales | Cualitativos con un orden o escala establecidos |
| **Boolean data** | Datos booleanos | Solo dos valores posibles, normalmente verdadero o falso |
| **Wide data** | Datos anchos | Cada sujeto tiene una sola fila con varias columnas de atributos |
| **Long data** | Datos largos | Cada fila es un punto temporal por sujeto; cada sujeto ocupa varias filas |
| **Static data** | Datos estáticos | No cambian una vez registrados |
| **Live data** | Datos en vivo | Se actualizan automáticamente |
| **Good data source (ROCCC)** | Fuente confiable | Fiable, original, completa, actual y citada |
| **Bad data source** | Fuente no confiable | Que no cumple ROCCC |
| **Bias** | Sesgo | Preferencia consciente o inconsciente a favor o en contra de alguien o algo |
| **Data bias** | Sesgo de datos | Cuando una preferencia distorsiona sistemáticamente los resultados del análisis |
| **Sampling bias** | Sesgo de muestreo | Sobre o subrepresentar miembros de una población por trabajar con una muestra no representativa |
| **Observer bias** | Sesgo del observador | Tendencia de distintas personas a observar las cosas de forma diferente (también *experimenter bias*) |
| **Interpretation bias** | Sesgo de interpretación | Tendencia a interpretar situaciones ambiguas de forma positiva o negativa |
| **Confirmation bias** | Sesgo de confirmación | Buscar o interpretar información de forma que confirme creencias previas |
| **Population** | Población | Todos los valores posibles de un conjunto de datos |
| **Sample** | Muestra | Segmento de la población representativo del conjunto |
| **Random sampling** | Muestreo aleatorio | Cada tipo posible de muestra tiene la misma probabilidad de ser elegido |
| **Unbiased sampling** | Muestreo insesgado | La muestra es representativa de la población en su conjunto |
| **Oversampling** | Sobremuestreo | Aumentar la muestra de grupos no dominantes para representarlos mejor |
| **Margin of error** | Margen de error | Diferencia máxima esperada entre el resultado de la muestra y el de la población real |
| **Confidence level** | Nivel de confianza | Probabilidad de que el tamaño de muestra refleje con precisión la población |
| **Confidence interval** | Intervalo de confianza | Rango de valores que expresa la probabilidad de que una estimación refleje la población |
| **Statistical significance** | Significancia estadística | Probabilidad de que los resultados de la muestra no se deban al azar |
| **Statistical power** | Potencia estadística | Probabilidad de que una prueba detecte un efecto que sí está presente |
| **Hypothesis testing** | Prueba de hipótesis | Proceso para determinar si un experimento o encuesta da resultados significativos |
| **Estimated response rate** | Tasa de respuesta estimada | Promedio de personas que suelen completar una encuesta |
| **Self-reporting** | Autoinforme | Técnica en la que los participantes aportan información sobre sí mismos |
| **Metadata** | Metadatos | Datos sobre los datos |
| **Descriptive metadata** | Metadatos descriptivos | Describen un dato y permiten identificarlo después |
| **Structural metadata** | Metadatos estructurales | Indican cómo se organiza un dato y a qué colecciones pertenece |
| **Administrative metadata** | Metadatos administrativos | Indican el origen técnico de un activo digital |
| **Metadata repository** | Repositorio de metadatos | Base de datos creada para almacenar metadatos |
| **Naming conventions** | Convenciones de nombres | Guías consistentes que describen contenido, fecha y versión en el nombre del archivo |
| **Data ethics** | Ética de datos | Estándares sobre cómo se recolectan, comparten y usan los datos |
| **Consent** | Consentimiento | Derecho a saber cómo y por qué se usarán los datos personales antes de cederlos |
| **Ownership** | Propiedad | Los individuos son dueños de los datos crudos que aportan y controlan su uso |
| **Currency** (ética) | Divisa | Los individuos deben conocer las transacciones financieras derivadas del uso de sus datos |
| **Transaction transparency** | Transparencia de transacción | Todo procesamiento y algoritmo debe ser explicable a quien aporta los datos |
| **Openness** | Apertura | Promueve el acceso, uso y compartición libre de los datos |
| **Data privacy** | Privacidad de datos | Preservar la información del sujeto en cada transacción de datos |
| **Data anonymization** | Anonimización | Proteger datos privados o sensibles eliminando la información identificativa |
| **Data security** | Seguridad de datos | Proteger los datos de acceso no autorizado o corrupción |
| **Data governance** | Gobernanza de datos | Proceso para la gestión formal de los activos de datos de una empresa |
| **GDPR** | RGPD | Organismo regulador de la Unión Europea para la protección de datos personales |
| **Database** | Base de datos | Colección de datos almacenada en un sistema informático |
| **Relational database** | Base de datos relacional | Serie de tablas que se pueden conectar formando relaciones |
| **Normalized database** | Base de datos normalizada | Cada tabla almacena solo datos relacionados entre sí |
| **Schema** | Esquema | Forma de describir cómo está organizado algo |
| **Primary key** | Clave primaria | Identificador cuya columna tiene todos los valores únicos |
| **Foreign key** | Clave foránea | Campo que es clave primaria en otra tabla |
| **Field** | Campo | Una pieza de información de una fila o columna; en una tabla, normalmente una columna |
| **Record** | Registro | Colección de datos relacionados en una tabla; sinónimo de fila |
| **Observation** | Observación | Los atributos que describen un dato contenido en una fila |
| **Attribute** | Atributo | Característica o cualidad usada para etiquetar una columna |
| **Data element** | Elemento de datos | Una pieza de información de un conjunto de datos |
| **Data model** | Modelo de datos | Herramienta para organizar elementos de datos y sus relaciones |
| **CSV file** | Archivo CSV | Archivo de texto delimitado que usa comas para separar valores |
| **Delimiter** | Delimitador | Carácter que indica el inicio o fin de un elemento de datos |
